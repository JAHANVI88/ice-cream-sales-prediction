# ice-cream-sales-prediction
Machine Learning project that predicts ice cream sales based on temperature using Linear Regression.


## Overview
This project uses Machine Learning to predict ice cream sales based on temperature.

## Objective
To analyze the relationship between temperature and ice cream sales and build a predictive model using Linear Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Model Training
5. Prediction
6. Model Evaluation

## Results
The model predicts ice cream sales with high accuracy based on temperature.
